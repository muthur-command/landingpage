# Landing page

**Muthur Command OS** pre-installed landing page. This is a small, temporary
page shipped with **Muthur Command OS** so something is displayed while
Supervisor is downloading the full **Muthur Command Core** on first
startup. The landing page opens a web server on port 8123 and publishes DNS-SD
discovery information. From that perspective the landing page is like a
stripped-down **Muthur Command Core** experience.

## Origin

- **Upstream:** [muthur-command/landingpage](https://github.com/muthur-command/landingpage) — first-boot UI while Muthur Command Core is installed, from which this tree was ported.
- **In this repo:** **Muthur Command** keeps this fork for **Muthur Command OS**; strings and behavior may diverge from upstream over time.
